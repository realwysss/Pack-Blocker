# PackBlocker

Blocks server-forced resource packs without loading them.

author as listed in the mod: Truefuly
license: MIT

## downloads

| jar | minecraft |
|---|---|
| `PackBlocker-1.0.0-fabric-mc1.21-1.21.11.jar` | >=1.21 <26.1 |
| `PackBlocker-1.0.0-fabric-mc26.1-26.2.jar` | >=26.1 <=26.2 |

the jars are on the releases page.

## source

no source was available, so the folders in this repo are decompiled from the release jars with cfr 0.152 (`src`) plus the resources from the jars (`res`).
